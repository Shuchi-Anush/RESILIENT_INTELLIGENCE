All four fixture files live under `graphify/tests/fixtures/.../obj/Debug/...` and are tracked because of the `.gitignore` negation rule `!**/fixtures/**`.

### 3a. `sample.AssemblyInfo.cs` and `App.AssemblyInfo.cs`

Both files have **exactly one changed line**:

```diff
-[assembly: System.Reflection.AssemblyInformationalVersionAttribute("1.0.0")]
+[assembly: System.Reflection.AssemblyInformationalVersionAttribute("1.0.0+ce8aab637c55aa5f7cb3aee9e438f50b79e4b2fa")]
```

The injected suffix `ce8aab637c55aa5f7cb3aee9e438f50b79e4b2fa` is the **full SHA of the current HEAD commit** (`ce8aab6`). This is standard .NET SDK behavior: `SourceRevisionId` / `AssemblyInformationalVersion` gets stamped with the current Git commit hash during a build.

Each `.cache` file is a single-line SHA-256 hash that changed:

| File | Old hash | New hash |

| `App.AssemblyInfoInputs.cache` | `583811af...` | `ffe68a8e...` |

The cache hash changes whenever the assembly-info inputs (including the commit hash) change — consistent with the `AssemblyInfo.cs` modification above.

### 3c. Timestamps

All four fixture files share a `LastWriteTime` of **2026-10-03 ~14:59** (within 1 second of each other). This strongly indicates a single .NET build/restore operation regenerated them together.

### Assessment
